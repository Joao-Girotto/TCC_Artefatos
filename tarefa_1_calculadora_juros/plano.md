# Cálculo de Juros Compostos no Terminal

Este projeto consiste em criar um script em Python para calcular juros compostos com base em entradas de valor principal, taxa de juros anual e período em anos. O script será executado no terminal com os valores de R$ 1000, 10% ao ano e 5 anos, e os resultados (incluindo o passo a passo anual) serão registrados.

## User Review Required
